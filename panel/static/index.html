使用帮助

快速开始

  1. 将目标设备通过 USB 连接到电脑
  2. 在有线模式下点击「扫描设备」检测设备
  3. 运行环境自检，确认设备满足部署条件
  4. 依次部署面板内核 (xwebd) 和语音助手 (sair)
  5. 切换至无线模式，输入设备 IP 连接，获得完整控制功能

两种模式

  • 有线模式 — 通过 USB/ADB 连接设备，适用于首次部署和基础操作（部署内核、部署助手、重启/关机、恢复出厂、查看面板日志）
  • 无线模式 — 通过 WiFi 连接设备端 xwebd 内核，提供完整控制功能（配置修改、插件管理、进程/文件管理、自检、三路日志等）

三模块架构

  • Panel — 运行在电脑上的 Web 控制面板（Python），端口 3000
  • xwebd（面板内核） — 运行在设备上的 HTTP 服务（C），端口 8080，作为面板与设备之间的桥梁，并托管插件
  • sair（语音助手） — 运行在设备上的语音助手进程（C），通过文件 IPC 与 xwebd 通信

无线模式功能导览

  • 设备状态 — 型号/CPU/内存/磁盘等系统信息、音量滑条、重启/关机/清理垃圾。清理垃圾会清空日志文件、旧版本备份与临时文件，不删程序本体
  • 面板内核管理 — 内核版本、日志采集级别与上传大小限制配置、更新/重启/卸载内核、Telnet 开关
  • 插件管理 — 设备上的独立进程插件，按需安装、崩溃不拖垮系统。「安装插件」自动列出本项目已构建的插件包及其说明，勾选即可安装；不再需要手动选文件。电池详情、灯控、USB 模式等插件功能都显示在对应插件条目内
  • 助手环境自检 — 检测语音助手运行环境（库文件、音频服务、ASR 引擎、WiFi 等）与运行时健康状态（配置读写、看门狗、WebSocket、电池）
  • 进程管理 — 设备进程清单与内存占用，核心进程受保护，可选进程可启停
  • 文件管理 — 浏览设备目录，上传/下载/删除文件。系统文件受保护不可删除
  • 语音助手管理 — 见下方「语音助手配置」与「更新方式」
  • 日志 — 三路日志实时查看：面板（本电脑）、面板内核（xwebd）、语音助手（sair），可按级别过滤、清屏、清理

语音助手配置

  • MCP 接入点 / 当前 WS URL — 实时显示当前生效地址；接入点从 xiaozhi.me 控制台获取，自建服务器填 WS URL，修改后保存生效
  • 每日使用时长管理（默认折叠）— 每日对话时长上限、使用时段限制（星期+多时段，支持跨午夜）、语音「再玩N分钟」、家长临时延长。达限后锁定唤醒，次日自动解锁
  • 激活 — 助手运行但未激活时点「激活」，获取激活码完成绑定；需设备 WiFi 已连接且能访问激活服务
  • 各配置项的详细说明：将鼠标悬停在 ! 小图标上查看

MCP 协议与工具

  • 语音助手通过 MCP (Model Context Protocol) 协议连接智能体，语音对话中可调用内置工具（查状态、调音量、控制屏幕、限时延长等）
  • MCP 工具列表见「语音助手管理」右侧，由助手固件内置
  • 不同设备的接入点可能不同，首次使用需在「MCP 接入点」配置正确地址

更新方式

  • 部署 — 全新安装或替换原生助手，设备会重启
  • 冷更新 — 替换已安装的自定义助手，设备会重启
  • 热更新 — 助手运行中无缝替换，设备不重启、对话不受影响（仅自定义助手支持）
  • 面板内核更新 — 无线模式下替换 xwebd 并自动重启设备

常见问题

  • 设备发热 — 语音唤醒引擎 7×24 运行属于正常现象，空闲时 CPU 占用约四分之一；面板已做闪存静默与轮询优化
  • 重启后连不上 — 设备重启需约 30 秒启动，面板会自动轮询重连，超时后手动点「连接」
  • 紧急修复 — 设备频繁重启无法正常操作时使用：高频轮询设备上线信号，一旦上线立即恢复出厂设置，不可撤销
  • 拦截每日动画 — 因已知死锁缺陷暂不可用（点击该项查看详情）

注意事项

  • 部署固件时请勿断开设备连接
  • 删除设备文件时请谨慎操作，系统文件不可删除
  • 插件可随时卸载重装，但「电池守护」卸载后失去低电保护，建议常驻
  • 设备音量也可由语音助手通过 MCP 协议控制（如「大声点」）
